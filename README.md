# Example Fire Pumps website
Static site (HTML, CSS, vanilla JS) for GitHub Pages.

**Before publishing**
1. Replace `YOURNAME` and `REPO` in `index.html`, `robots.txt`, `sitemap.xml`, `404.html`.
2. Replace `IMAGE_PLACEHOLDER_*` with files in `assets/` (keep width/height and alt text accurate). Add a 1200x630 image for Open Graph.
3. Replace brand, phone, email, flow ranges and approvals (UL, FM, etc.) with verified data.
4. Create a Formspree form (or similar) and set its ID in the form `action`.
5. Push, then enable Settings > Pages > Deploy from branch.
